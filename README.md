# SkyRoll-Game
SkyRoll is a 2D platformer game prototype built using C++ and SFML.
Jump across floating platforms, collect coins, avoid deadly hazards, and reach the exit to complete levels.

✨ Features
✔️ Multi-level gameplay
✔️ Smooth camera movement
✔️ Coin collection system
✔️ Multiple platform types:
🧱 Static platforms
🔄 Moving platforms
 Vanishing platforms
⚠️ Hazard platforms
✔️ Lava & environmental dangers
✔️ Simple and clean game mechanic

🛠️ Tech Stack
Language: C++
Library: SFML

🚀 Getting Started
🔧 Prerequisites
Install SFML
C++ compiler (g++, clang, etc.)

▶️ Run the Game
Bash
g++ PlatformerPrototype.cpp -o SkyRoll -lsfml-graphics -lsfml-window -lsfml-system
./SkyRoll

📂 Project Structure

SkyRoll/
│── PlatformerPrototype.cpp
│── assets/
│    ├── textures/
│    ├── sounds/
│    └── screenshots/

🎯 Gameplay
Use keyboard controls to move and jump
Collect coins to increase score
Avoid falling into lava
Reach the door to complete the level
